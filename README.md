# X Media Downloader

Download videos and GIFs from X as MP4 files in Chrome or Edge.

## Installation

1. On GitHub, choose **Code → Download ZIP** and extract the files.
2. Open `chrome://extensions` or `edge://extensions` and enable **Developer mode**.
3. Click **Load unpacked** and select the folder containing `manifest.json`.

## Usage

Open a post on X and click the extension icon or press **Alt+Shift+V**. If the download doesn't start, the extension opens the FxTwitter player so you can download the file there.
